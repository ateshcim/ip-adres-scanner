# ip-adres-scanner
 Codexe'r Dev - Modern IP Analiz Aracı nedir, ne işe yarar?

Codexe'r Dev - IP Analiz Aracı, hedef IP adreslerinin ülke, şehir, bölge, zaman dilimi, ISP (organizasyon) ve harita koordinatlarını saniyeler içinde masaüstünüze getiren, yüksek hızlı ve gelişmiş bir sorgulama aracıdır.

Öne Çıkan Özellikleri:

 Modern & Şık Arayüz: Siyah konsol ekranları yerine göz yormayan, karanlık mod (Dark Mode) destekli estetik masaüstü tasarımı.

Kapsamlı Veri Analizi: Tek tıkla hedef IP'ye ait tüm coğrafi verileri, ISP (organizasyon) ve harita koordinatlarını anında sorgulama.

Donmasız Altyapı: Akıllı Thread mimarisi sayesinde yüksek hızlı sorgulamalarda bile arayüzde donma veya "Yanıt Vermiyor" hatası yaşatmaz.

Taşınabilir (.EXE) & Güçlü: Kurulum gerektirmez, doğrudan tek bir .exe dosyası olarak dilediğiniz her yerde çalışır.

Gelişmiş Lisans Sistemi: Uygulamayı kullanabilmek için size özel tanımlanan lisans anahtarını (key) girmeniz gerekmektedir.
